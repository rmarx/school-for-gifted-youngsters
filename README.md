# School for gifted youngsters

X-men themed vibe-coded application to show off Akamai Functions and the Spin Framework

Currently deployed at [https://4b2f6faf-a8a5-4370-8543-7c31e0a05838.fwf.app/](https://4b2f6faf-a8a5-4370-8543-7c31e0a05838.fwf.app/).

## Getting Started

Build the App

```bash
spin build
```

## Run the App 

```bash
spin up
```
